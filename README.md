# Zero to Apex

A career mode for Automobilista 2. Pick your next race in the app, hit Play, and the game sets itself up.

## Download

Get the latest installer from the [Releases page](https://github.com/thingsbyjosh/zta-releases/releases/latest). Once installed, the app updates itself.

Each release lists what changed and how to install it.

## Help with your language

The app ships in twelve languages. English and Spanish are written by hand. The other ten are a first pass, and they get better when people who actually speak them fix what reads wrong.

The language files live in [`locales/`](locales). You can correct a translation or add a language that isn't there yet with a pull request. [`locales/TRANSLATING.md`](locales/TRANSLATING.md) explains how, and [`locales/COVERAGE.md`](locales/COVERAGE.md) shows how complete each language is.
